# Thierry Kuate Mabap

**Applied Mathematics · Scientific Computing · Data Science**

## Research background

- **AIMS Senegal master's research:** inverse parameter estimation in PDE models for population dynamics, combining mathematical modelling, numerical methods and data-driven inference.
- **University of Dschang master's research:** age-structured modelling of hepatitis C virus dynamics, including macrophages and antiviral treatment; existence, uniqueness, reproduction numbers and stability analysis, supported by MATLAB simulations.
- **Submitted manuscript:** S. M. Manou-Abi, T. Kuate Mabap and A. Attiogbe (2026), *A Numerical and Statistical Framework for Parameter Estimation in Age-Structured Population Dynamics Models*, submitted to the *Journal of Mathematical Biology*.

## Methods and tools

**Mathematics:** PDEs and ODEs, dynamical systems, structured population dynamics, inverse problems, numerical analysis and optimisation.

**Computing:** Python, NumPy, SciPy, pandas, scikit-learn, Matplotlib, NetworkX, PyTorch, MATLAB, Jupyter, Git and LaTeX.

**Research directions:** scientific machine learning, mathematical epidemiology, parameter estimation, causal inference and topological methods for data analysis.
